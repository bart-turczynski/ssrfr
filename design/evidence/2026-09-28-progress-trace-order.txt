# Reading: the order is the build's. On 8.14.1 the first progress call comes a libcurl round
# before `Trying`, so ssrfr, which cancels a transfer after the round a callback failed in,
# stops a progress callback that fails on its first call with no `Trying` traced: check
# `absent`. On 8.5.0 the first progress call precedes `Trying` within one round, and on
# 7.76.1 and 7.81.0 `Trying` is traced first; on all three that round traces `Trying` before
# the transfer is cancelled, so the pin can match and the attempt ends `callback-error`.
# The loopback listener takes IPv4 only; the ::1 dial is refused after `Trying`, which still
# shows the order.
